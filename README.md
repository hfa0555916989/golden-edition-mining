# الإصدار الذهبي للتعدين والمقاولات

موقع تعريفي عربي (RTL) مبني بـ Next.js (App Router) + TypeScript + Tailwind، مع لوحة تحكم كاملة على `/admin`.

## لوحة التحكم
- **السيو SEO**: العنوان، الوصف، الكلمات المفتاحية، صورة OG، عناوين الأقسام. الموقع يولّد meta / OpenGraph / Twitter و `sitemap.xml` و `robots.txt` و JSON-LD (LocalBusiness).
- **الهوية**: رفع الشعار والأيقونة، الألوان، الخط (Tajawal / Cairo)، تكبير وتصغير الشعار (منفصل للكمبيوتر والجوال).
- **الوسائط**: رفع صور وفيديوهات بأي حجم ومقاس (رفع مباشر إلى Vercel Blob من المتصفح)، ترتيب، حذف، تعليقات.
- **المحتوى**: كل النصوص، الخدمات، المدن، المشاريع، لماذا نحن، أرقام التواصل، روابط التواصل الاجتماعي، التذييل، إظهار/إخفاء الأقسام.

المحتوى يُحفظ كملف JSON في Vercel Blob ويظهر مباشرة بدون إعادة نشر. بدون توكن Blob يعمل الموقع بالمحتوى الافتراضي (`lib/defaults.ts`).

## متغيرات البيئة
| المتغير | الوصف |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور لوحة التحكم |
| `ADMIN_SECRET` | نص عشوائي طويل لتوقيع جلسة الدخول (cookie) |
| `BLOB_READ_WRITE_TOKEN` | يُضاف تلقائياً عند ربط Vercel Blob بالمشروع |
| `NEXT_PUBLIC_SITE_URL` | (اختياري) رابط الموقع للـ sitemap و OG |

## التشغيل
```bash
cp .env.example .env.local
npm install
npm run dev
```
